# 🚀 Week 1: Arrays, Sorting Basics & Java Functional Features

Welcome to **Week 1** of the Problem Solving and Testing journey! This week is dedicated to establishing strong foundations in 1D/2D array manipulation, prefix sum accumulation, two-pointer techniques, custom object sorting using comparators, and modern Java functional programming features (lambdas).

---

## 🎯 Learning Objectives & Algorithmic Paradigms

- **Prefix Sum Accumulation:** Computes running cumulative totals to answer range queries and equilibrium balance points in linear $O(N)$ time.
- **Two-Pointer Convergence:** Solves sorted array transformations (e.g., squaring negatives and positives) in single-pass $O(N)$ time without full $O(N \log N)$ sorting.
- **2D Grid Traversal:** Iterates through nested array structures to compute row-wise aggregations and find global extrema.
- **Custom Comparators & Multi-Field Sorting:** Leverages `Comparator<T>` and lambda expressions to implement complex ordering criteria across multiple object attributes.
- **Java Functional Programming (Lambdas):** Employs `@FunctionalInterface` and lambda expressions for dynamic numeric validation (odd/even, primality testing, palindrome detection).
