# Problem Solving & Testing - 4 Week Track

This repository contains Java-based problem-solving exercises completed over a four-week learning plan. The focus is on arrays, strings, sorting, collections, matrices, dates, and core algorithm patterns used in coding interviews and technical assessments.

## Overview

- 4 weeks of practice
- 36 solved exercises
- Primary language: Java
- Topics covered: arrays, strings, maps, sorting, matrices, comparators, priority queues, and date/time logic

## Weekly Roadmap

| Week | Focus Area | Problems |
| --- | --- | ---: |
| Week 1 | Arrays, sorting basics, lambdas, comparators | 7 |
| Week 2 | Sliding patterns, grouping, frequency maps, array operations | 8 |
| Week 3 | Collections, priority queues, date/time, custom sorting | 10 |
| Week 4 | Matrix operations, string checks, conversions, duplicates | 11 |
| Total |  | 36 |
