# Java Lab Experiments

A collection of Java lab experiments covering functional programming, streams, algorithms, and object-oriented design.

| Exp. No. | Title | Folder |
|---|---|---|
| 1 | Salary Transformation System Using Functional Programming Techniques | [01-Salary-Transformation-System](./01-Salary-Transformation-System) |
| 2 | Real-Time Stream Analytics Engine Using Stream Processing Concepts | [02-RealTime-Stream-Analytics-Engine](./02-RealTime-Stream-Analytics-Engine) |
| 3 | Maximum Profit Analyzer Using Kadane's Algorithm | [03-Maximum-Profit-Analyzer-Kadane](./03-Maximum-Profit-Analyzer-Kadane) |
| 4 | Intelligent DNA Pattern Search System Using KMP Algorithm | [04-DNA-Pattern-Search-KMP](./04-DNA-Pattern-Search-KMP) |
| 5 | Banking Transaction System Using Object-Oriented Programming | [05-Banking-Transaction-System-OOP](./05-Banking-Transaction-System-OOP) |
| 6 | Ride Sharing Platform Simulator Using OOP and Polymorphism | [06-RideSharing-Platform-Simulator](./06-RideSharing-Platform-Simulator) |

Each folder contains its own `.java` source file and a `README.md` with run instructions and a short explanation of the approach.

## Requirements
- JDK 8 or higher

## Running Any Experiment
```bash
cd <experiment-folder>
javac *.java
java <MainClassName>
```
